# Protein Store

A full-stack e-commerce website for protein supplements and fitness products.

## Tech stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express (coming soon)
- **Database:** MongoDB with Mongoose (coming soon)
- **Auth:** JWT (coming soon)
- **Payments:** Razorpay test mode (coming soon)

## Features (planned)

- Product search, filtering, sorting and pagination
- Cart, wishlist and checkout
- User accounts and order history
- Product reviews and ratings
- Admin dashboard

## Getting started

```bash
cd client
npm install
npm run dev
```

The app runs at http://localhost:5173
